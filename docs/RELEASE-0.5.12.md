# Finance Suite 0.5.12

## Alcance documentado

Esta versión corresponde a la base anterior a la integración de la previsión recurrente de la versión 0.5.13.

- Ajustes de diseño del dashboard y edición/consulta de movimientos.
- Mejoras de sincronización bancaria y reconciliación de cuentas tras renovar autorizaciones.
- Refactorización de servicios y adaptadores Java para mejorar separación de responsabilidades.
- Homogeneización de las pantallas Importar y Movimientos.
- Correcciones de visualización de iconos bancarios, incluidos Trade Republic y Kutxabank.

## Trazabilidad

Estos cambios se integraron en distintas PR sobre master (#30, #31, #32 y #33). **No todos constituyeron una publicación independiente etiquetada 0.5.12**; este documento es una reconstrucción del tramo previo a 0.5.13, no una certificación de artefactos publicados.

## Verificación

No se dispone aquí de evidencia de compilación completa, pruebas de integración ni despliegue Docker de este conjunto de cambios.
